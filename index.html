Personal Home Assistant backup connection

Google OAuth application display name: calendar

This page describes the Home Assistant Google Drive backup connection operated by the owner of this personal account. It is used to store and retrieve that owner’s Home Assistant backups in their own Google Drive. It is not a public sign-up service.

What the connection does

Home Assistant can create, read, update and delete the specific Drive files used with this app, including deleting old backups according to the configured retention settings. Its requested permission is https://www.googleapis.com/auth/drive.file, rather than unrestricted access to every file in Drive.

Authorization is completed on Google’s consent screen and returned to the owner’s Home Assistant instance. This information website does not ask for passwords, authorization codes or backup files.

Privacy and support

Read the privacy notice for storage, revocation and deletion details. Contact the owner through the support email displayed on the Google consent screen. This notice describes this Home Assistant backup client; it does not claim to document unrelated clients that may exist in the same personal Google Cloud project.

This personal connection is not an official Google service and this website is not operated by the Home Assistant project.
